# 数据库说明

数据库连接仅在本机 `.env` 配置。所有迁移和运行时连接都会验证当前数据库是 `tutor_workspace`；不匹配即停止。迁移器不创建、删除或切换数据库，也不会在安装、启动、构建时自动执行。

## 迁移

```powershell
pnpm db:migrate
```

迁移文件位于 `database/migrations/`，由 `schema_migrations` 记录版本、校验和和应用时间。当前业务范围包含：学生、合同、学习记录、学习计划、任务定义、任务分配、账号/会话/审计数据底座，以及体验学生与 `trial` 体验合同。

回退以应用回退为主，保留已应用迁移和数据；不提供自动删表或清库命令。

## 初始管理员

```powershell
pnpm db:init-admin -- --apply --confirm
```

该命令只可在本机交互式终端运行。它会先检查批准库和启用管理员数量，隐藏读取并二次确认密码；成功时仅输出非敏感摘要。命令不会自动运行，不会从命令参数或环境变量读取密码。

## 合成开发数据

`database/seeds/` 中的脚本仅用于明确执行的合成开发数据装载。它们不读取 mock JSON、不覆盖已有业务数据、不清库，且要求数据库存在恰有一名启用管理员以满足关联字段。执行前请阅读各脚本的固定样例与重复运行约束。
