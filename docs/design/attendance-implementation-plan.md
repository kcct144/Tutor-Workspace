# S10 出勤实施计划与完成记录

- 状态：已实现，待验收
- 范围：真实 MySQL 出勤记录、API、`/attendance` 页面和审计接入。

## ATT-P2-01 / ATT-P3-01 修复完成

1. 已删除更新路径的共享锁读取；没有“共享读锁再升级写锁”的并发模式。
2. 更新使用 `student_id + attendance_date + period + version + status<>目标状态` 的单条条件更新：写入成功才递增版本；条件不满足后以独占当前读区分同状态无副作用成功与版本冲突。
3. 重复创建映射为 `409 VERSION_CONFLICT`；同版本、同目标状态为成功无副作用，不更新时间、版本或审计；其他旧版本均为 `409`。基础设施/连接错误继续安全映射为 `503`，不自动重试。
4. 已新增不连接数据库的事务模拟测试，覆盖创建、重复创建、陈旧版本、同状态、同版本并发、审计失败回滚，以及 409 JSON/no-store envelope。

1. 新增版本化迁移 `015_attendance_records.sql` 与 `016_audit_attendance_record.sql`，迁移器继续逐次检查批准库、校验和和已登记结构。

4. 清理仅属于出勤的 mock 数据、mock service、`/prototype/attendance` 路由、匿名豁免和原型测试；主导航只保留真实 `/attendance`。

## 运行与回退

迁移须人工显式执行：`pnpm db:migrate`。重复运行只校验后跳过；不会自动创建出勤业务数据。应用回退仅撤回页面/API 接入，保留已迁移表与审计能力；本计划不提供自动删表或数据清理。
