# 学生标签与工作台筛选

状态：已实现，2026-09-13 完成自测；真实标签保存未操作生产学生，详见交付记录。

## 产品约定

- 标签为人工维护的学生分类，与科目、计划和业务状态独立。
- 学生详情维护 0–10 个标签，每个标签去除首尾空白后为 1–24 个 Unicode 字符，规范化 NFC，精确去重，区分大小写；不允许控制字符。
- 标签以名称标识，不提供全局改名或删除；移除只解除当前学生的标签。历史学生默认无标签。
- 工作台单选标签与年级组合（AND）筛选，只展示在读学生，顶部全部在读人数不受筛选影响。标签选项来自全库实际使用的标签，支持分页搜索；筛选后页码归 1。
- 详情独立编辑标签，先保存学生再维护标签。保存失败/冲突保留草稿，用户明确重新加载才替换草稿；不触碰其他表单草稿。

## 实施步骤

1. 019 新增 student_tags，学生外键 RESTRICT，学生/标签复合主键及标签/学生索引；不回填数据。
