# 体验学员与一次性体验合同实施计划

- 状态：迁移已应用；等待真实 API 与浏览器验证（2026-09-07）
- 依据：`docs/prd/student-management.md`、`docs/prd/contracts.md`

## 已确认范围

1. 学生姓名是唯一由用户提交时必填的基础字段；`grade` 可为 `NULL`，非空时仍限既有五个年级枚举。
2. 新增一次性 `trial` / 体验合同。它只需学生与科目，日期/课时字段均为空、需补课数固定为 0、不记录金额。
3. `trial` 有存储型生命周期：`active` / 进行中、`terminated` / 已终止。仅 `active` 参与学生有效科目聚合；两态都没有到期日。
4. 该生命周期仅适用于 `trial`。既有四类合同继续按日期或课时派生其原有只读状态。

## 实施切片

1. **迁移与模型**：新增单一版本化迁移，允许 `students.grade` 为 NULL，并为 `contracts` 增加仅体验合同使用的 `trial_status` 及精确 CHECK。迁移执行器维持 `tutor_workspace` 校验、显式运行与校验和保护；不迁移数据、不运行种子。
2. **后端与聚合**：扩展学生/合同 DTO、校验与数据访问层。普通档案新增、编辑允许省略/清空年级；`trial` 创建时服务端固定 `active`。合同查询、详情、列表筛选和学生科目聚合识别活动体验合同；体验合同没有到期日。
3. **状态变更**：提供仅对体验合同的显式终止入口，使用 `expectedVersion`。本切片采用保守的单向 `active -> terminated`，重复终止幂等、不可恢复；任何恢复需求需单独确认，避免将终止合同意外重新计入科目。
4. **前端与脚本**：学生表单将年级变为可选。合同页展示体验类型与状态，并只对进行中的体验合同提供终止入口。将 `contract-data.mjs` 扩展为创建与终止命令；合同创建与学生创建保持两步、各自预览/确认/回读，绝不隐式联写。
5. **测试与交付**：覆盖 NULL 年级、体验字段互斥、活动/终止聚合、版本冲突、终止幂等、脚本缺失字段提示和结果不明停止。完成格式、类型、Lint、相关单元、真实 API（无真实业务数据写入时标记 SKIP）和构建。

实现状态：1–4 已完成；第 5 项的静态及隔离单元验证完成。`011` 已由显式迁移器在批准库应用，未创建体验学生或体验合同；真实 API 聚合验证必须由持有本机登录会话的用户在获准环境中显式执行。

## 数据与安全边界

- 所有运行时和迁移写入仅在批准的 `tutor_workspace`；每次写前复核当前库。
- 日常脚本只走 S8.7 本机登录会话与回环 API；不得把电话号码置于命令参数、日志或聊天中。
- 不增加金额、付款、删除、合同续签、任务/学习记录功能，也不创建学生+合同的一次性联写 API。

## 验收口径

- 无年级学生可被创建、查询与后续版本化补填；已有年级筛选保持原义。
- `trial` 默认进行中，英语出现于有效科目，`expiryDate` 为 null；终止后英语退出有效科目，其他合同不受影响。
- 缺少学生 ID、科目或登录会话，重复学生未确认、版本冲突或结果不明时，脚本停止且不自动重试。
