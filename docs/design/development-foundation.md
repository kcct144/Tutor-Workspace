## 范围

本设计仅定义 Nuxt 应用启动、依赖注入、云端 MySQL 连接配置和代码质量检查。它不包含学生、跟进、任务、提醒、权限或任何业务规则。基础模板采用客户端渲染；后续如确认需要公开内容或 SEO，再单独设计 SSR。

## 约定

- 前端页面位于 `app/pages/`，可复用界面位于 `app/components/`，布局位于 `app/layouts/`。
- Nitro API 位于 `server/api/`；MySQL池、查询、事务位于 `server/db/`，通用响应在 `server/utils/`。旧MySQL工具入口已在S1移除。
- S1已获授权在 `database/` 引入最小显式迁移与合成装载，不在安装/启动/构建时自动执行；只建学生基础所需表。详见[学生数据模型](student-data-model.md)和[数据库说明](../../database/README.md)。
- 跨端类型位于 `types/`；单元测试位于 `tests/`。
- 环境变量仅由 `.env` 注入，不提交该文件；变量清单维护在 `.env.example`。

## 连接策略

MySQL仅通过用户在未提交的.env中填写的云端连接信息访问；每次获取连接先验证批准数据库边界，API统一处理错误且不输出真实配置。连接池按需创建，不在模块导入时连接。
