## 范围

本设计仅定义 Nuxt 应用启动、依赖注入、云端 MySQL/可选 Redis 连接配置和代码质量检查。它不包含学生、跟进、任务、提醒、权限或任何业务规则。基础模板采用客户端渲染；后续如确认需要公开内容或 SEO，再单独设计 SSR。

## 约定

- 前端页面位于 `app/pages/`，可复用界面位于 `app/components/`，布局位于 `app/layouts/`。
- Nitro API 位于 `server/api/`；跨 API 的服务端基础设施位于 `server/utils/`。
- `database/` 预留给后续迁移和种子数据；当前不引入迁移工具或真实数据表。
- 跨端类型位于 `types/`；单元测试位于 `tests/`。
- 环境变量仅由 `.env` 注入，不提交该文件；变量清单维护在 `.env.example`。

## 连接策略

MySQL 仅通过用户在未提交的 `.env` 中填写的云端连接信息访问。Redis 没有预设部署位置，仅在环境变量提供 URL 或主机信息时可用。两个客户端都按需创建，不在模块导入时连接；后续业务 API 应显式调用对应客户端，并自行处理连接错误。
