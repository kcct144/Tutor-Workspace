## 当前确定的规则

- 学生报名学习以合同为业务依据，不以学生直接绑定科目为依据。
- 一个学生可以同时拥有多个合同；一个合同只对应一个科目。
- 合同类型固定为四类：月卡、半年卡、年卡、按课时。
- 月卡、半年卡、年卡必须记录开始时间和结束时间。
- 按课时合同必须记录已上课时数和总课时数；当前原型按上课时数达到总课时数判定“已用完”。
- 所有合同都记录通用的“需补课数”字段。
- 首页学生卡片和学员管理表格展示的科目，均从该学生合同聚合而来；卡片使用普通文字，表格使用标签。
- 当前原型按合同科目去重展示；学生到期时间暂取有结束日期的合同中的最新日期，按课时合同不参与到期时间聚合。

## 原型实现范围

已实现合同管理页面 `/contracts`：支持合同列表、学生/科目/合同类型/状态筛选、关键词搜索、分页、新增合同和编辑合同。列表将开始时间、到期时间、已上课时、总课时、需补课数分别展示；时间类合同的课时字段显示“—”，按课时合同的日期字段显示“—”。操作只更新当前浏览器会话中的 mock 状态，不会永久保存。金额、付款、附件等未确认字段暂不展示。

合同类型使用固定选项：月卡、半年卡、年卡、按课时。页面不额外展示“参数”字段；按课时合同直接填写已上课时数和总课时数，补课数对所有类型可填写。

## 待总指挥确认的问题

1. 按课时合同是否也有有效期？如果有，是否需要填写并参与学生到期时间计算？
2. 已上课时数由排课/任务完成自动扣减，还是由学管师手动登记？是否允许部分课时？
3. “需补课数”是由缺课/请假记录自动生成，还是由学管师手动维护？补课完成后如何扣减？
4. 月卡、半年卡、年卡按自然月/自然半年/自然年计算，还是仅作为展示类型、日期由人工填写？
5. 合同是否需要合同编号、金额、签署状态、付款状态、附件等字段？
6. 合同页面需要支持作废、续签、复制等操作吗？作废是否需要保留审计记录？
7. 科目是否维护独立字典表；当前原型直接记录合同科目文本，不建立学生—科目中间表。

## 验收标准

- 一个学生可关联多个合同，每条合同只有一个科目和一个固定合同类型。
- 合同类型只能选择月卡、半年卡、年卡、按课时四类。
- 月卡、半年卡、年卡新增或编辑时必须填写开始时间和结束时间，且结束时间不得早于开始时间。
- 按课时新增或编辑时必须填写总课时数和已上课时数，已上课时数不能小于 0 且不能超过总课时数。
- 所有合同都可以填写需补课数，且不能小于 0。
- 合同管理页可按学生、科目、合同类型和状态筛选，并支持关键词搜索与分页。
- 列表将开始时间、到期时间、已上课时、总课时、需补课数拆分为独立列；不适用字段显示“—”。
- 新增或编辑合同后，列表在当前浏览器会话内即时更新。
- 按课时合同已上课时数达到总课时数时显示“已用完”，否则按开始时间显示“未开始”或“生效中”。
- 首页学生卡片在年级旁展示该学生合同聚合后的一个或多个科目文字；学员管理表格展示科目列，多个科目以标签展示。
- 同一学生重复科目在页面上不会重复展示；无合同科目的学生不渲染空标签。
