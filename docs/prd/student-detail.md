## 页面结构

1. 基本信息区：固定展示学生姓名、年级/班级、学校、性别、到期时间、建档时间、主要监护人、监护人联系方式、备注、进行中的学习计划，并保留当前状态、负责学管师、最近跟进。
2. 学习记录区：记录学生的学习表现，分类为“缺、补、强”；支持筛选、关键词搜索、分页和新增记录。
3. 任务列表区：展示当前学生任务；本版使用 mock 数据，支持状态筛选、关键词搜索和分页，任务定义与分配模型详见 `docs/design/task-data-model.md`。

### 基本信息字段

姓名、年级、学校、性别、到期时间、建档时间、主要监护人、监护人联系方式、备注、进行中的学习计划、当前状态、负责学管师、最近跟进。

基本信息在桌面端以左侧窄栏吸顶展示，学习记录和任务列表占据右侧主区域；移动端自动恢复上下布局。详情页顶部不重复展示大号学生姓名，学生身份由基本信息区承担。

## 学习记录字段与规则

| 字段     | 说明                                       |
| -------- | ------------------------------------------ |
| 发生日期 | 事情发生日期                               |
| 分类     | 缺：需要补足；补：已完成补救；强：表现突出 |
| 内容     | 学管师随时记录的具体表现，必填             |
| 记录人   | 当前登录学管师，原型中使用王老师           |

新增记录表单要求分类、发生日期、内容均不能为空；提交后记录插入列表顶部，仅在当前浏览器会话有效。

## 筛选与分页

- 学习记录支持按分类筛选：全部、缺、补、强。
- 学习记录支持按发生日期范围筛选。
- 学习记录支持按内容关键词搜索。
- 任务列表支持按任务状态筛选和标题关键词搜索。
- 两张表独立分页，默认每页 5 条。
- 无结果时展示各自空状态。

## 验收标准

- 进入 `/students/:id` 后，基本信息、学习记录、任务列表三个区域均可见。
- 基本信息区展示姓名、年级、学校、性别、到期时间、建档时间、主要监护人、监护人联系方式、备注和进行中的学习计划。
- 学习记录可以按分类和关键词筛选，分页与任务列表互不影响。
- 学习记录可以按日期范围筛选，并可与分类、关键词组合使用。
- 学习记录新增表单对分类、日期、内容做必填校验；提交后立即显示在列表顶部。
- 任务列表可以按状态和标题筛选，并显示分页与空状态。
- 两个列表均复用 `BaseDataTable`，不在页面内重复实现表格分页结构。
- 不存在的学生 ID 展示 404 空状态，不渲染错误的学生信息。
- 页面明确使用原型数据，刷新后不承诺保留新增记录。
