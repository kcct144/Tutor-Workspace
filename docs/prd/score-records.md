# 成绩记录

- 状态：S9 第一版已实现，待受控环境验收
- 页面：`/scores` 与学生详情中的“成绩记录”区

成绩记录是独立的结构化数据；不会改写学习记录正文、合同、学习计划、任务或学生聚合字段。

## 范围

一条成绩记录固定包含日期、科目、类型、考试名称、得分和满分。类型仅为“小测”（`quiz`）或“考试”（`exam`）。

- 日期为 1900-01-01 至服务端 Asia/Shanghai 当天。
- 科目使用现有统一 `Subject` 校验（trim 后 1–64 字）；页面从既有科目选项服务选择，不新增成绩专属自由词表。
- 考试名称 trim 后为 1–160 字。
- 得分与满分是最多两位小数的十进制字符串；得分不小于 0、满分大于 0、得分不超过满分。
- 得分率由服务端按 `score / fullScore * 100` 派生并返回，不持久化、不作为页面录入字段。
- 同一学生同日期、同科目、同名称可有多条记录，不建立业务唯一约束。

支持独立页和学生详情内的列表、关键词搜索、学生/科目/类型/日期范围筛选、分页、新增和编辑。不支持删除、导入导出、批量录入、排名、学期、图表、家长报告或自动联动。

## 保存与冲突

创建和编辑都使用当前网页登录会话的身份；浏览器不能传创建人、修改人、审计字段或版本以外的系统字段。编辑须提交 `expectedVersion`；过期版本返回 409，页面保留草稿并提供显式“重载最新版本”入口。

保存成功会回读数据库记录。网络或服务异常不会自动重复创建请求。

## 页面体验

`/scores` 默认每页 10 条；学生详情每页 5 条。列表按日期倒序、ID 倒序稳定排序。页面区分 loading、空结果、错误和保存中状态；保存中禁用重复提交。独立页可选择学生，学生详情新增时自动绑定当前学生。

成绩区域使用真实 API，不再有 `/prototype/scores`、JSON mock、sessionStorage 或“不会永久保存”提示。

## 当前访问边界

所有成绩 API 都在现有全局会话、回环访问、Cookie/CSRF 边界内。当前学生读写层尚未实现负责人范围隔离；本期不在成绩模块单独扩展该权限模型。未登录请求会被全局鉴权拒绝，写请求还须通过 CSRF 校验。
