# 学习计划文档模块（第一版原型需求）

- 状态：待确认
- 负责人：产品经理兼前端原型负责人
- 创建日期：2026-09-05
- 最后更新日期：2026-09-05
- 关联需求：P0-学习计划、P0-首页工作台、P0-学生详情

## 目标

将学习计划作为可阅读、可编辑的 Markdown 文档管理。学管师进入页面后，可以快速从左侧文档列表选择计划，在右侧阅读正文，并在需要时编辑和保存。

## 当前确定的范围

- 页面路由为 `/plans`。
- 页面采用左右两栏：左侧为学习计划文档导航，右侧为当前文档正文。
- 左侧列表展示文档标题、摘要和最近更新时间，并支持关键词搜索。
- 右侧默认展示 Markdown 渲染后的正文；支持标题、段落、列表、引用、粗体、行内代码、任务清单和简单表格。
- 点击“编辑计划”进入 Markdown 文本编辑状态；支持取消和保存。
- 保存只更新当前浏览器会话中的 mock 状态，不会永久保存，页面明确展示“原型数据 · 仅本次会话有效”。
- 当前阶段不实现新建、删除、导入导出、版本历史、多人协作、后端持久化和权限控制。

## 页面与字段

### 学习计划页面 `/plans`

| 区域     | 字段/控件     | 说明                                 |
| -------- | ------------- | ------------------------------------ |
| 左侧导航 | 搜索计划      | 按标题、摘要、正文关键词过滤         |
| 左侧导航 | 文档标题      | 点击切换当前文档                     |
| 左侧导航 | 摘要          | 文档列表中最多展示两行               |
| 左侧导航 | 更新时间      | 展示最近一次 mock 更新时间           |
| 正文头部 | 文档标题      | 当前文档标题                         |
| 正文头部 | 文档摘要      | 当前文档摘要                         |
| 正文头部 | 编辑计划      | 进入编辑状态                         |
| 编辑状态 | Markdown 正文 | 多行文本，可修改原始 Markdown        |
| 编辑状态 | 取消          | 放弃当前未保存修改                   |
| 编辑状态 | 保存          | 校验正文非空并更新当前会话 mock 数据 |

## 关键状态流转

```text
阅读态 ──点击编辑──> 编辑态 ──保存──> 阅读态（内容更新）
   │                   │
   └──切换文档─────────┴──取消──> 阅读态（放弃修改）
```

- 文档未选中：展示空状态。
- 搜索无结果：左侧展示“没有找到匹配的学习计划”。
- 编辑正文为空：阻止保存并展示错误提示。
- 编辑中切换文档且存在未保存修改：弹出浏览器确认，确认后放弃修改并切换。

## Mock 数据与接口替换边界

- 类型：`app/types/plans.ts` 中的 `StudyPlanDocument`。
- 数据：`app/mocks/data/plans.json`。
- 服务：`app/mocks/services/plans.ts` 的 `getStudyPlans()`。
- 页面仅依赖服务返回的类型化数据；后续可将服务替换为 `GET /study-plans` 和 `PUT /study-plans/:id`，不改变页面交互结构。

## 待总指挥确认的问题

1. 学习计划是否需要关联一个或多个学生；当前原型暂按独立文档列表展示。
2. Markdown 文档是否需要新建、删除、复制、导入和导出能力。
3. 是否需要版本历史、自动保存、草稿状态和多人协作编辑。
4. 正式环境采用服务端 Markdown 渲染还是前端渲染；是否允许图片、链接、HTML 等扩展语法。
5. 文档访问权限按学管师、团队还是角色划分。

## 可测试验收标准

- 访问 `/plans` 可看到左右两栏，左侧列出 mock 学习计划，右侧展示默认文档正文。
- 点击左侧不同文档，右侧标题、摘要和正文同步切换。
- 输入关键词后，左侧列表只保留标题、摘要或正文命中的文档；无结果时显示空状态。
- 正文正确渲染标题、段落、列表、引用、粗体、行内代码、任务清单和简单表格。
- 点击“编辑计划”后显示 Markdown 多行编辑器，并隐藏阅读正文。
- 修改 Markdown 后点击保存，回到阅读态且正文展示修改结果；刷新前仍保留本次会话修改。
- 正文为空时点击保存不会更新文档，并显示“正文不能为空”。
- 编辑中点击取消，正文恢复到进入编辑前的版本。
- 编辑中存在未保存修改时切换文档，取消确认不会切换，确认后才切换。
- 页面及操作均明确这是原型数据，不会永久保存。
