# 学生标签

状态：已实现（含学生详情左栏组合）。

学生详情的左侧基础档案栏提供“学生标签”编辑区，可输入多个标签，保存后在工作台学生卡片展示；标签不占用右侧学习记录、成绩记录与任务列表工作区。新学生先创建档案，再维护标签。历史学生默认无标签。

每位学生最多 10 个标签，每个标签为去除首尾空白后的 1–24 个 Unicode 字符，NFC 规范化、精确去重、区分大小写，不允许控制字符。标签独立于科目、计划和学生状态；不修改任何关联业务。

工作台提供单选标签筛选，可与年级组合使用，切换后回到第一页。卡片仍仅展示在读学生，顶部全部在读人数不受筛选影响。选项为实际使用中的标签，支持搜索及分页，不从当前卡片列表推断全部选项。

移除标签只解除当前学生的标签，不删除学生。暂不提供全局改名、批量打标签或独立标签管理页面。

写入复用登录、CSRF、学生版本保护及事务审计；冲突保留标签草稿，重新加载前明确确认，不覆盖学习记录等其他草稿。

实现与数据模型见 [实施计划](../design/student-tags-implementation-plan.md)，验证见 [交付记录](../test/student-tags-delivery.md)。

2026-09-14 布局优化后，`StudentTagsPanel` 通过 `BasicInfoPanel` 的 footer 插槽放在“进行中的学习计划”之后。嵌入模式只去除自身白色背景、边框和外层留白，并使用分隔线与档案字段区分；查询、编辑、保存、版本冲突和草稿保护逻辑没有复制或修改。页签切换不销毁标签组件，学生 ID 改变时沿用其既有重新初始化机制。
