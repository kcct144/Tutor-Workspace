## 目标

为学管师提供可快速浏览、筛选和进入详情的学员列表。当前阶段只实现前端高保真原型，使用模拟数据，筛选和分页状态仅在浏览器会话内生效。

## 页面字段

| 字段     | 说明                               |
| -------- | ---------------------------------- |
| 姓名     | 学员主标识，点击操作可进入详情     |
| 学校     | 学员当前就读学校                   |
| 班级     | 学员当前班级                       |
| 学习计划 | 计划名称，多个计划以标签展示       |
| 科目     | 来自合同的科目，多个合同以标签汇总 |
| 状态     | 在读、待分配、已结课               |
| 到期时间 | 当前学员服务或课程到期日期         |
| 操作     | 查看详情                           |

## 筛选与操作

- 支持按学员姓名关键词搜索。
- 支持按年级筛选：全部、初一、初二、初三、高一、高二。
- 支持按状态筛选：全部、在读、待分配、已结课。
- 筛选器外部单独显示“年级”“状态”标签，下拉选项仅显示具体值，避免重复前缀。
- 支持清空筛选条件。
- 表格分页；默认每页 8 条。
- 点击“查看详情”进入 `/students/:id`。

## 状态规则

| 状态   | 含义                               |
| ------ | ---------------------------------- |
| 在读   | 当前仍由学管师负责跟进             |
| 待分配 | 已建档但暂未分配学管师             |
| 已结课 | 学习服务已结束，不计入首页在读数量 |

## 可复用组件

新增 `BaseDataTable` 通用表格组件，统一承载 Ant Design Vue Table 的列定义、分页、加载态和空状态；任务列表等后续页面仅需传入 columns、dataSource 和单元格插槽。

## 待总指挥确认的问题

1. “待分配”学员是否应由学管师在此页直接分配，还是只由管理员操作？
2. 学员列表默认排序按最近跟进时间、创建时间，还是到期时间？本版暂按最近跟进倒序。
3. “已结课”学员是否默认隐藏，还是与在读学员一并展示？本版保留状态筛选。

## 验收标准

- 页面以表格展示学员，展示姓名、学校、班级、学习计划、科目、状态、到期时间七个业务字段，并保留查看详情操作。
- 年级和状态筛选可以分别使用，也可以组合使用，结果即时更新。
- 搜索学员姓名时按关键词过滤；清空后恢复全部结果。
- 无匹配结果时显示空状态，不显示错误的残留行。
- 分页切换只影响当前列表视图，不修改模拟数据。
- 点击“查看详情”进入对应学生详情页。
- 表格通过通用组件渲染，后续页面可通过传入列定义和插槽复用。
