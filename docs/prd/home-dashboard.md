## 本轮确定的需求

首页以学生卡片为主要信息区，取消独立数据区与问候语。页面顶部保留工作台标题、在读学生数量、添加学生/新建任务快捷操作和年级筛选。卡片固定高度，响应式网格自动适配屏幕宽度；每张卡片展示学生姓名、年级班级、学习计划标签、右下角详情入口。学习计划直接展示标签，不增加“学习计划”字段标题。学生在 7 天内到期时，在姓名旁展示“n 天后到期”状态标签。任务区拆分为“未完成”和“已完成”两组，各最多显示 3 条；超过 3 条时显示剩余数量提示。任务通过复选框在本次浏览器会话中切换完成状态，已完成任务显示删除线。

## 待总指挥确认的问题

1. 首页顶部是否需要保留“添加学生”和“新建任务”快捷操作，还是只保留导航与年级筛选？
2. 学习计划标签是否允许一名学生关联多个计划，以及标签的最大展示数量？
3. 任务完成状态是否允许学管师直接在首页修改，还是只能进入任务详情修改？
4. 学生卡片是否需要显示风险标记、最近跟进时间等字段？本版按“卡片紧凑优先”暂不展示。

## 验收标准

- 页面不出现独立数据统计区、问候语、头像或无业务价值的副标题。
- 视口宽度变化时，卡片按可用空间平滑换列，不出现固定列宽溢出；卡片高度保持一致。
- 切换任一年级后，仅展示该年级学生；选择“全部”恢复全部学生。
- 每张卡片按未完成、已完成分组；每组最多渲染 3 条任务，已完成任务有复选框选中态与删除线。
- 当任一任务组超过 3 条时，组末显示准确的剩余任务数量。
- 点击任务复选框后，卡片内状态立即更新；刷新页面后不承诺保留。
- 点击“查看详情”进入对应学生详情路径；无数据时展示空状态。
- 快捷操作在原型阶段给出轻量提示，不发起真实后端请求。
