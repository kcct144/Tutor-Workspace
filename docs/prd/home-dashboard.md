## 本轮确定的需求

首页以学生卡片为主要信息区，取消独立数据区与问候语。页面顶部保留工作台标题、在读学生数量、添加学生/新建任务快捷操作和年级筛选。卡片固定高度，响应式网格自动适配屏幕宽度；每张卡片展示学生姓名、年级与合同科目（普通文字同一行）、学习计划标签、右下角详情入口，不展示班级。学习计划直接展示标签，不增加“学习计划”字段标题。学生在 7 天内到期时，在姓名旁展示“n 天后到期”状态标签。任务区拆分为“未完成”和“已完成”两组，各最多显示 3 条；超过 3 条时显示剩余数量提示。任务通过复选框调用真实API切换并持久化完成状态，已完成任务显示删除线。

应用 header 仅保留图形 logo，不显示“学管师工作台”文字，以减少横向占用；logo 链接仍保留无障碍名称。

## 已确认范围

1. 保留快捷操作轻量提示，不新增学生写能力。
2. 真实多对多计划标签，按计划ID区分。
3. 允许首页复选框切换完成状态，与分配页及学生详情同步。
4. 不扩展风险标记与额外卡片字段。

## 验收标准

- 页面不出现独立数据统计区、问候语、头像或无业务价值的副标题。
- 视口宽度变化时，卡片按可用空间平滑换列，不出现固定列宽溢出；卡片高度保持一致。
- 切换任一年级后，仅展示该年级学生；选择“全部”恢复全部学生。
- 每张卡片按未完成、已完成分组；每组最多渲染 3 条任务，已完成任务有复选框选中态与删除线。
- 每张卡片在年级旁展示来自合同的一个或多个科目文字，多个科目用顿号分隔；不展示班级信息。
- 当任一任务组超过 3 条时，组末显示准确的剩余任务数量。
- 点击复选框提交期间禁用该项；成功后刷新真实分组与计数，失败保留确认状态并提示，刷新后持久化一致。
- 点击“查看详情”进入对应学生详情路径；无数据时展示空状态。
- 快捷操作仅给轻量提示，不发起范围外写请求。

## S6 本轮确认（取代原型数据与待确认口径）

只展示在读学生卡片，顶部activeStudents为全部在读数；grade仅筛卡片，服务端分页默认20最大100。GET /api/home/list仅page/pageSize/grade，返回Page<HomeStudent>加activeStudents/asOfDate（Asia/Shanghai当天）。卡片显式id/name/grade/school/status、真实subjects/expiryDate/expiresInDays/plans、pendingTasks/completedTasks（各<=3）、pendingCount/completedCount和pendingRemaining/completedRemaining。没有监护人信息。

合同聚合复用有效合同规则，0<=expiresInDays<=7显示到期提示；计划为真实{id,title}。任务摘要JOIN当前定义显示标题/科目/说明，不保存快照；完成记录不标逾期。未完成按dueDate/id升序，完成按completedAt/id降序，准确总数不来自摘要长度。

保留响应式卡片、年级联动和既有快捷操作提示，不扩展学生新增或风险标记。任务复选框调用统一completion接口，提交禁用、失败保持确认状态并提示、成功刷新分组和计数；跨页/窗口聚焦重读。loading/empty/error明确且无mock回退。最多三条/剩余数由服务端返回；无任务显示暂无任务。

验收：仅在读、筛年级不改顶部数、正常分页、准确两组计数/剩余数、7天合同提示、真实计划、三处状态一致、失败恢复、同版本冲突、响应式布局。数据边界仅S6写分配，S1–S5不变。
