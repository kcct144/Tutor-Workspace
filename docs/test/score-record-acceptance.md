# 成绩记录验收方案（S9）

- 状态：实现完成，真实账号浏览器验收待执行

## 结构与安全

- 运行迁移两次：首次仅在 `tutor_workspace` 新建成绩表并扩展审计 CHECK；第二次按校验和跳过。
- 确认没有历史成绩回填，且学生、合同、学习记录、计划、任务和分配表未被迁移改写。
- 匿名成绩 API 返回 401；写请求缺少/错误 CSRF 返回 403；浏览器不可传 actor、创建人、修改人或审计字段。

## 数据规则

- 小测和考试允许；其他类型、未知字段、未来日期、1900 年前日期、空白/超长科目或名称均拒绝。
- 覆盖 `0/100`、`87.5/120`、`100/100` 及最多两位小数；三位小数、科学计数法、负数、满分 0、得分超满分拒绝。
- 同学生同日期同科目同名称的两条创建允许。
- API 返回得分率但表中无持久列。

## 查询、编辑与页面

- 列表验证学生、科目、类型、日期和关键词组合，`%/_` 按字面匹配；越界页为空且 total 准确。
- 学生详情只读取该学生且每页 5 条；独立页每页 10 条。
- 保存后回读；双窗口旧版本返回 409 且草稿不丢失；明确重载才替换草稿。
- 验证 loading、empty、error、保存禁用、320/375px 筛选换行、侧栏可操作和表格横向滚动。
- 验证历史原型路由、mock、sessionStorage 提示均不存在。

## 已知验收前提

真实写入验收需要受控的已登录管理员会话和预先批准的非生产测试数据。本次实现不创建学生、账号或成绩测试数据；没有该前提的真实浏览器/API 写入项须标记 SKIP，不能伪称已通过。
