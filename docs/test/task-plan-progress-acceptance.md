# 任务关联学习计划与计划任务完成度验收标准

- 状态：S11 真实实施中
- 最后更新日期：2026-09-08
- 关联模块：任务定义、任务分配、学习计划、学生详情

## 数据与接口

1. `018_task_plan_progress.sql` 只扩展 `tasks` 与 `task_assignments`；两列可空、外键均为 RESTRICT、索引存在；已有任务和分配不回填，旧分配快照为 `NULL`。
2. 任务新增、编辑、详情和列表通过真实 `studyPlan:{id,title}|null` 使用计划 ID；同名计划不按标题混淆。任务编辑清空关联或改关联使用乐观锁，不回写历史分配快照。
3. 计划选项使用有分页和 LIMIT 的 `GET /api/study-plans/options`，不从当前任务列表伪造。
4. `POST /api/task-assignments/create-batch` 只接收 `taskId/studentIds,dueDate`。服务器在同一事务锁定任务、验证全部学生、验证当前计划关联、写同一计划快照和审计。任一学生不匹配时返回 `409 STUDENT_PLAN_NOT_LINKED`，整个批次零写入。
5. 浏览器传入 `studyPlanIdSnapshot`、`assignedBy`、操作人或其他未知字段一律被拒绝；无会话为 401，写请求继续受 CSRF 保护。

## 真实页面验收

| 编号  | 场景                 | 预期                                                                                     |
| ----- | -------------------- | ---------------------------------------------------------------------------------------- |
| UI-01 | `/tasks` 新增或编辑  | 可加载、选择、改选或清空一份计划；列表和详情显示真实关联或“未关联”。                     |
| UI-02 | `/tasks/assignments` | 选任务后显示是否需要计划校验；服务端 409 时表单选择与草稿保留，不出现部分成功。          |
| UI-03 | `/students/:id`      | 每个当前关联计划显示快照完成数/总数；分母为零显示“暂无任务”，不是 0%。                   |
| UI-04 | `/plans`             | 显示当前关联任务与当前关联学生的快照完成度；当前任务关系和历史快照统计可不同且均可解释。 |
| UI-05 | 完成/恢复分配        | 任务完成度和页面计数刷新；历史分配继续 JOIN 最新任务标题、科目和说明。                   |
| UI-06 | 窄屏                 | 320px、375px 与桌面下选择器、提示、卡片和表格可操作、可阅读。                            |

## 自动化覆盖

- 迁移白名单与首次/重复结构复核；任务关联、清空、同名计划 ID、快照为空和历史不回写。
- 关联计划任务的成功批量分配、混入未关联学生的 409 零写入、非法快照字段、任务后续改计划。
- 学生和计划聚合的已完成/总数、`empty` 状态、分页/筛选、版本冲突、审计事务、匿名访问与 JSON/no-store 错误 envelope。

不验收任务系列、自动派发、自动顺延、计划正文解析进度、协作、历史回填、删除恢复、Redis 或未确认负责人权限模型。
