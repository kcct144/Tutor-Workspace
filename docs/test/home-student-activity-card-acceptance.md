### 浏览器与证据边界

已有管理员会话下实测待办/动态、空状态、真实计划和学生标签。首页不再显示已完成组、完成数比值或“查看详情”链接。卡片非控件区域点击、Enter、Space 进入学生详情；计划标签进入对应计划、不误跳学生详情。浏览器截图检查配合只读 DOM 尺寸检查，确认卡高 510px、活动最多 5 条、动态不超出卡片。最终桌面实际宽度1800，document scrollWidth=clientWidth=1781，无横向溢出。

浏览器存在缩放比例，响应式以实际 `innerWidth` 校准而非仅以设置参数计数：375 CSS px 时 document scrollWidth=clientWidth=356；320 CSS px 时均为306（差值为滚动条）；未横向溢出。首次发现原首页工具栏/年级项溢出，修复后复测通过。桌面检查同样维持固定高度。

DATA-01/02/04/05：真实只读核对 + 单元投影；DATA-03：SQL 明确仅使用 created_at、静态/单元覆盖，未编辑真实记录。API-01：advisor 权限和分页顺序单元覆盖；真实浏览器仅验证现有管理员，不创建学管师账号。UI-01：隔离状态测试验证成功刷新和失败保留；未点击真实任务复选框制造完成数据。复选框 stop 事件隔离有组件源码断言，实际写入点击未验证。不把这些未执行写入场景计为真实浏览器通过。
