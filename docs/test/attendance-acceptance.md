# S10 出勤验收标准

- 状态：实现完成，验证记录见 `attendance-delivery.md`。

| 编号   | 验收项   | 预期                                                                                             |
| ------ | -------- | ------------------------------------------------------------------------------------------------ |
| DB-01  | 迁移     | 仅在 `tutor_workspace` 创建出勤表并扩展审计白名单；复跑不改变结构或数据                          |
| DB-02  | 唯一性   | 相同学生、日期、时段第二次创建被拒绝，不产生第二行                                               |
| API-01 | 鉴权     | 未登录请求出勤 API 返回统一 401；写入仍需 CSRF                                                   |
| API-02 | 校验     | 仅接受固定时段/状态、有效月和白名单字段；未来日期仅接受有课                                      |
| API-06 | 取消排课 | 空单元格为无课；仅当前版本的“有课”记录可取消回空，已形成结果的记录不可清空，取消与审计同事务     |
| API-03 | 并发     | 陈旧版本和并发创建返回 409，原记录不被覆盖；同版本同状态重放无副作用，版本、维护时间和审计均不变 |
| API-04 | 查询     | 月度结果使用筛选与明确上限；今日汇总仅统计已记录格，全部时段按人次                               |
| API-05 | 审计     | 创建/更新与出勤审计同一事务，审计摘要无联系方式或会话秘密                                        |
| UI-01  | 矩阵     | 默认当前月、在读、上午；姓名列固定、日期可横滚、昨天/今天定位有效                                |
| UI-02  | 编辑反馈 | 单格保存中、成功、失败回滚和冲突草稿保留均可见；不自动重试                                       |
| UI-03  | 响应式   | 320px、375px 和桌面筛选可操作，状态有图标外的文字 tooltip/标签                                   |
| UI-04  | 路由     | 主导航只链接真实 `/attendance`，旧原型路由和 mock 不再可用                                       |
